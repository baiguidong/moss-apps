# 更新记录

## 0.1.1

首次公开发布。内置 Whisper、FFmpeg 与完整多语言 base 模型，支持本地音频转写、播放定位、字幕编辑及导出。提供 Agent 工具入口。

支持 macOS Apple Silicon（darwin-arm64）。固定运行依赖随包提供，首次使用在本机还原并校验，无需额外下载引擎或安装查看软件。
