# 更新记录

## 0.1.1

首次公开发布。内置 sharp/libvips，支持格式转换与压缩、缩放填充、鼠标拖拽裁剪、旋转翻转、色彩与清晰度、文字水印和元数据。Moss 内预览、对比、导出，Agent 可通过 5 个工具独立操作。

支持 macOS Apple Silicon（darwin-arm64）。固定运行依赖随包提供，首次使用在本机还原并校验，无需额外下载引擎或安装查看软件。
