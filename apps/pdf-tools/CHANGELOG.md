# 更新记录

## 0.1.1

首次公开发布。内置 PDF.js、pdf-lib、Canvas、Tesseract 与中英文 OCR 数据，支持页面处理、渲染、文字与 OCR 结果查看。Moss 内预览及导出，提供 Agent 工具入口。

支持 macOS Apple Silicon（darwin-arm64）。固定运行依赖随包提供，首次使用在本机还原并校验，无需额外下载引擎或安装查看软件。
