# 布局与图形规范

按内容类型阅读对应段落。这里保留原版的设计约束；Codex 专用样式、库与组件的替换见 adaptation.md。

## 界面预览

- 预览一个设计时默认显示一个界面；用户明确要求多个变体时，才制作本地切换的轮播，不自动切换。预览切换控件属于会话外框，不属于被展示产品。
- 使用已有产品与平台上下文，不为制作会话预览而搜索整个项目。匹配产品导航、字体、配色和内容；没有设计资料时根据平台与要求推断。
- 产品内使用根节点作用域内的产品专用颜色、字体、表面和控件，不套用通用可视化样式。这优先于通用样式规则。
- 只有外层会话表面透明，产品窗口、卡片、菜单、浮层应不透明，浮层位于内容上方。除非指定固定主题，产品配色也跟随宿主主题。
- 小组件、对话框、移动屏幕用紧凑产品表面，外部预览区可加低调、适配主题的点阵。全页桌面窗口和应用外壳占满宽度，不再包一张卡片；图表和讲解不加点阵。
- 全局导航与选择器放在产品外壳，局部控件放在所属组件。单选项无需选择器；显示真实状态，不发明填充卡片、仪表盘或超大图标。需要可检查 UI 时不伪造截图。

## 日程

使用核实后的日期与事件，以紧凑时间轴呈现时长及重叠分栏。短事件块保留标题，通过 hover、焦点或轻触展示完整标题、时间和详情。不要为次要文字拉长日程或再包卡片。Moss 未提供 viz-calendar，需自行实现相同行为，不能直接放置未注册的自定义元素。

## 交互讲解与模拟

紧凑控件或状态、一个主要图形，最多一行当前选择详情。默认不放摘要卡；只有变化指标是核心时才用至多三个。裁掉空白，适应可用宽度。分步讲解只添加所需的步骤控件并更新当前图形；未要求时不加参数、公式、指标卡或并排步骤。

## 图表与统计图

- 简单、直接标注的数值使用 SVG；复杂数据需要比例尺、图例和布局时可使用已内嵌且核实的库，不能加载网络脚本。
- 图形、图例和子图直接位于透明表面。仅绘图区有细框，不能再加卡片、填色面板或阴影。
- 每个笛卡尔子图使用独立响应式 SVG，viewBox 与实际容器匹配；提供可见的 X/Y 数量与单位标签。可沿用 text.axis-title[data-axis="x"/"y"] 和 rect[data-chart-frame] 标识。
- 用 ResizeObserver 监听大小，按实测宽度重画，Y 轴预留至少 64px。从全部观测、误差和参考值求带留白的范围，不猜测或写死数据域。比例尺为标记半径留边，线条与端点不能跑出绘图区。
- 每次重绘后一起检查刻度、轴题和数据标签，标签至少相隔 4px，边缘标签向内对齐；先移除可选标注，不缩字。360px 宽时 X 轴最多四个刻度，子图纵向堆叠。
- 系列最多六种主题色并循环使用，文字和轴线用中性色；SVG 标签通常 12px，不能小于 11 屏幕像素。图表太密时拆成共享比例尺的小图，不隐藏用户要求的维度。
- 保留观测、趋势与重要数值。密集不确定性用带状区域，孤立估计用误差线。一个紧凑可换行图例；系列开关用原生按钮、aria-pressed、小色块和中性文字，无边框、胶囊或选中色背景。切换时同步线、点和提示行。
- 多系列共用一个根节点相对定位、pointer-events:none 的 role="tooltip" 浮层；全绘图区提供交互覆盖层。引导线精确跟随鼠标 X，对所有可见系列插值，在同一 X 展示标记和提示，不吸附到最近样本。触屏可轻触固定同一组详情。
- 若内嵌 D3，查找有序观测使用 d3.bisector(d => d.x).center(values, x)，不能把 accessor 传给 d3.bisectCenter。
- 独立标记的透明命中区域在鼠标下至少 32 屏幕像素，触屏约 44px；密集散点用单个最近点覆盖层。
- 命名数值与一次性分析直接从图开始，把数值与结论放在标记、轴或标注上；未要求时不加 KPI 行、控件和面板。
- 顺序或并行工作用同一时间轴的对齐泳道，用标记编码阶段与资源；总量、等待、瓶颈标在轴或泳道上。多指标或分布比较使用共享尺度的小多图，同时呈现每个要求的维度，不藏在切换按钮后。
- 简单直接标注图可省略提示；其他图表保留适当提示与原生分组图例，不能用单点自制提示替代多系列交互。提示含名称、数值与单位，支持键盘和触屏。
- 图形、SVG、Canvas 都有简洁的屏幕阅读器描述（role、可访问名称、title/desc 或隐藏描述）。给最长格式化标签留空间，不能与边界、轴、图例和标记重叠；通过调整或减少标签解决。SVG 样式限定到图表，不能影响同容器内图标。

## 地图

地图占主要空间，最多一个紧凑的选择/详情区，仅保留所需控件。采用已发布 GeoJSON/TopoJSON 和有来源的经纬度，用经过核实的投影处理；不能手绘或硬编码真实地理轮廓。只有用户要求示意图时才用示意地图。

世界国家可使用 @d3-maps/atlas@1.0.0 的 world/countries/countries-110m，配合 topojson-client@3.1.0 的 feature(world, world.objects.features).features。其 feature.properties.id 已是 ISO3，直接关联输入 ISO3，不能转数字。美国州县可取 us-atlas@3/counties-10m.json；邮编/ZCTA 和城市边界用官方 Census 或当地开放数据，不猜路径，不把原始 JSON 当 JavaScript 导入。

这些资料由模型在制作阶段获取、核实并内嵌，页面运行时不能发网络请求。局部点位应配有已发布的街道、街区等地理背景，空白区域或单独行政轮廓不算底图。显示完整城市或区域，点位四周适度留白。交付前实际打开，修正空白底图、导入失败、缺失标签和未投影点。

## 密集分类网格

一个紧凑横向选择摘要、网格、一个小图例。每格只有一个清晰标识符，其他元数据放无障碍标签或单行摘要，不堆徽章和信息网格。未要求时只支持选择。

## 构成比例或时间分配

紧凑指标加每期一个类别堆叠图；不能换成仅总量柱图，也不重复制作热力图加总量图。

## 控件、表格和图标

- 相关输入与按钮同排垂直居中，标签与数值放上方。按钮按内容宽度；每组最多一个主要操作。只有确需占满行才用整行按钮。原生链接承担链接，原生输入、select、textarea 承担输入。
- 勾选框与文字用 label 包裹，或通过 for/id 关联，使整行可点击；滑块前显示当前值和单位。
- 标签页使用有名称的 tablist、原生 button role=tab、唯一 id、aria-controls 和 aria-selected；对应 tabpanel 配 id/aria-labelledby，非激活面板 hidden。Moss 不自动接管行为，需实现切换。单纯展示不必使用标签页。
- 补充提示支持 hover、焦点和触屏；不能只用 title，也不能隐藏必要内容。截断标签需可获取完整文字。提示避让边界。
- 语义表格保持安静、无外围框，单元格可换行、细横分隔线、无竖线。数字尾部对齐并用等宽数字；空间不足时减少 padding，不缩小文字。必要时局部横向滚动，不能撑破整个可视化。
- 次要文字只能用于单位、时间、背景信息；错误色仅用于需处理的错误。代码用 code/pre；隐藏描述不可见但可被屏幕阅读器读取。
- 原版用预置 Lucide，Moss 当前没有该全局对象。优先有文字的按钮；需要图标时只使用核实过并内嵌的标准图标，不凭空编造图标路径、不联网加载图标库。装饰图标 aria-hidden，只有图标的按钮必须有可访问名称。
