# 0.1.2

默认全局常驻，模型无需选择 App 或搜索即可使用。配合新版 Moss 支持元素、文字、区域标注，在选区旁输入后直接发送至主会话，保留草稿并支持排队；普通工具栏移除重新载入和整体继续修改。补回原版 skill 的创作规则，并明确中文适配与运行时差异。

# 0.1.1

为 Moss 通用 App 详情页提供介绍和三个自然语言试用示例。默认全局可用，无需在会话中选择。新版 Moss 支持从“常用”和“打开”进入同一详情页，查看技能说明、启停、权限和使用范围；App 不包含独立业务 UI。

# 0.1.0

首版主会话可视化 App，无独立工作台。支持消息内交互、模型控制右侧展示、状态同步、带上下文追问、保留旧版的修改、模板与全局 skill，以及 HTML/SVG/CSV/JSON 导出。
