# 更新记录

## 0.3.4

- 新增 HyperFrames 动画工坊 App，支持本地 HTML/CSS 场景、分镜项目、视频渲染和产物导出。

## 0.3.3

- 渲染记录增加明确的「查看视频」入口，点击整行、右侧箭头或使用键盘均会定位并聚焦上方播放器。
- 播放器显示所选成片的生成时间；重复点击同一记录也能返回播放器，加载失败时可重新尝试。
- 验证四条历史成片的选择、正确导出，以及桌面和窄屏下的播放器可见性。

## 0.3.2

- 明确 Agent 工具、会话入口及创作指引的时间规则：每个镜头的动画从本镜头 0 秒计时，不能累加前序镜头时长。
- 保存场景与校验项目时返回超出镜头时长的 CSS 动画延迟警告，覆盖动画简写、独立延迟、多个动画以及秒/毫秒值。
- 明确结构校验、编码完成与成片画面验收的区别，要求检查各镜头内容及结尾。

## 0.3.1

- 修复主会话项目选择器的 `composer.list` 输出 schema，避免项目列表因数组/对象不匹配被宿主拒绝。
- 修复多分镜合成时间偏移，避免第 5 秒后空白；场景内动画从各镜头起点播放。
- 保存场景或分镜后立即更新合成 HTML；读取已有项目时使用最新场景，未完成的场景仍阻止渲染。
- 修复已完成任务的结果解析，恢复 App 内 MP4 播放与导出，补充加载失败后的重试。
- 对齐 Moss 主题、绿色主按钮、浅深色背景、字号和工作台间距。
- 增加 15 秒三镜头逐帧检查，以及包含真实任务结果结构的播放、拖动、重试和导出验证。

## 0.3.0

- 重做视频创作工作台：项目导航、创作需求、大画面预览、分镜与历史成片。
- 输入框下方提供悬浮示例，点击快速填入需求；「开始创作」打开已关联 App / 项目的主会话草稿。
- 新增主会话资源与会话内工作台，支持返回对应项目；保存分镜和场景后实时同步。
- 收起高级代码与渲染设置，补充使用指南、错误说明、重试和取消。
- 修复安装包遗漏 `hono` 等生产依赖的问题，显式使用随包 FFmpeg/ffprobe，并增加隔离打包与实际 MP4 渲染验证。
