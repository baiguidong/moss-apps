# 更新记录

## 0.2.2

移除 `dataset:share` 权限、跨 App 数据协议和共享数据源页面及后台接口。保留本地文件预览、SQL 查询、导出、常规工具和 CLI skill，工具调用授权由 Host 处理；不声明其他 App 的数据或工具依赖。

## 0.2.1

后台改为按需启动，任务执行期间向 Host 续约保持活动；任务产物由 Host 提供链接，页面减少闲置轮询并按需读取大结果。需要 Host API 3.20.0。

## 0.2.0

新增 `moss.dataset/v1` 只读能力：显式添加和取消共享文件，其他 App 可经 Host 发现数据源、读取结构与预览、执行受限查询并分页读取结果。查询支持来源 revision 校验。

共享文件路径按字面值读取，避免 DuckDB 通配符扩大读取范围；结果缓存增加容量上限、到期清理和取消共享清理，来源 revision 纳入 ctime。

## 0.1.0

首次提供DuckDB 本地数据查询和导出；页面与 Agent 共享任务记录和结果。
