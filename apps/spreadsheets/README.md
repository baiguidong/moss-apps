# 表格

在主会话中创建、读取和修改 Excel 表格，计算公式并预览数据。

会话中的 Excel 预览提供「编辑工作簿」。在同一个标签页编辑并保存到当前工作簿，通过模式下拉框继续查看。编辑器的「历史记录」按时间列出初始发布所创建的版本与每次保存前的快照。预览工具栏提供导出。

在「更多 → 表格」打开独立工作台，可以从最近工作簿继续，或打开本地 XLSX、CSV、TSV。「打开报价示例」创建两张带跨表公式的工作表。

工作台使用随包提供的 Univer 开源核心 1.6.1，支持编辑单元格值和公式、重算、撤销与重做。读取已有表格的数字格式、基本字体与背景颜色、列宽、冻结行列和合并区域。新改动通过现有 XLSX 后端保存。工作台导入和示例保存在 App 实例数据目录，通过会话工具生成的工作簿版本保存在所属会话工作区，可从预览的模式下拉框进入。

工作簿默认打开原始预览，底部标签切换工作表。顶部下拉框提供原始预览、工作表视图和编辑工作簿。
