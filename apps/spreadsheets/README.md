# 表格

在主会话中创建、读取和修改 Excel 表格，计算公式并预览数据。

会话中的 Excel 预览提供「编辑工作簿」。在同一个标签页编辑并保存到当前工作簿，点击「返回预览」继续查看。编辑器的「历史记录」按时间列出初始发布所创建的版本与每次保存前的快照。预览工具栏提供导出。

在「更多 → 表格」打开独立工作台，可以从最近工作簿继续，或打开本地 XLSX、CSV、TSV。「打开报价示例」创建两张带跨表公式的工作表。

工作台使用随包提供的 Univer 开源核心 1.6.1，支持编辑单元格值和公式、重算、撤销与重做。读取已有表格的数字格式、基本字体与背景颜色、列宽、冻结行列和合并区域。新改动通过现有 XLSX 后端保存。工作台导入和示例保存在 App 实例数据目录，通过会话工具生成的工作簿版本保存在所属会话工作区，可通过结果中的「编辑工作簿」进入。

交互表格预览使用 TanStack Table Core 8.21.3，支持按实际数值排序、搜索格式化内容、分页、列显隐、工作表切换和重置视图。状态按工作表保存并与 Moss 另一处预览同步；原行号和公式提示保留，操作不改写 XLSX。原文件仍是主成果，`result.interactivePreview` 与 `result.displayMarkdown` 提供交互预览入口。

预览数据共享约 900 KiB 的预算。超过时显示实际载入行数，并说明搜索、排序范围。完整数据保存在 XLSX 和工作簿 JSON。没有 JavaScript 时预览显示前 25 行、40 列的静态表格。交互预览 HTML 带完整脚本及 MIT 许可，可离线打开。

验证：`bun run --cwd apps/spreadsheets test`、`bun run --cwd apps/spreadsheets test:preview`（后者需要 Playwright Chromium）。
