# Changelog

## 0.2.0

- 接入 Moss 通用 Agent Channel，可配置自动回复、人工回复、AI 草稿审核与仅 @ 回复。
- 增加 Agent、工具、技能、连接器白名单和固定/轮换/单次会话策略。
- 支持按已配对成员覆盖回复方式，并在 App 内处理人工消息与待审核草稿。
- 要求 Moss Host API 1.2，新增草稿投递确认、崩溃重放和敏感 Turn 数据脱敏。

## 0.1.3

- 飞书设置页改用 Moss 桌面端统一的颜色、表面、控件和状态样式。
- 移除与宿主标题重复的 App 品牌区，调整为紧凑的设置分组布局。
- 完整跟随 Moss 的浅色、深色与背景样式，并在外观变化时动态同步。

## 0.1.2

- 将飞书配置集中到 App 设置页。
- 增加完整配置说明、配对管理和密钥掩码。
- 修复保存配置后 App 页面与 Desktop 状态不同步的问题。
- 管理页仅保留运行控制和日志，不再重复展示业务配置。
