配置说明

按顺序完成以下设置，然后再生成配对码。

打开飞书开放平台
1. 创建应用并添加机器人
  1. 在飞书开放平台创建“企业自建应用”，并添加机器人能力。
  2. 进入“凭证与基础信息”，复制 App ID 和 App Secret 到上方。
  3. 长连接模式不需要填写公网回调地址、Encrypt Key 或 Verification Token。
2. 开通权限

在“权限管理”中开通以下权限：

  • im:message.p2p_msg:readonly — 接收私聊消息
  • im:message:send_as_bot — 以机器人身份回复
  • im:message — 获取与发送消息
  • im:resource — 获取与上传图片或文件
  • cardkit:card:write — 创建和流式更新卡片
3. 配置事件与回调
  1. 在“开发配置 → 事件与回调 → 事件配置”选择“使用长连接接收事件”。
  2. 添加 im.message.receive_v1 和 application.bot.menu_v6。
  3. 切换到“回调配置”，同样选择长连接，并添加新版 card.action.trigger。不要选择旧版 card.action.trigger_v1。
4. 配置机器人菜单

在“应用能力 → 机器人 → 机器人配置”添加三个“推送事件”菜单：

  • 会话中心：moss.sessions
  • 新建会话：moss.new_session
  • 停止执行：moss.stop
5. 发布并完成配对
  1. 创建并发布新的应用版本，确认应用可用范围包含实际使用者。
  2. 在上方保存配置，等待状态显示“飞书长连接已就绪”。
  3. 生成 6 位配对码，在飞书中私聊机器人并发送该码。
数据存储与安全

App ID、白名单和配对关系等配置由 Moss Host 持久化；App Secret 等敏感字段会写入 App 凭据库。配置页只会收到 **** 掩码，飞书 Backend 启动时才会在隔离的实例上下文中取得明文。迁移期间，原“IM 接入”配置仍作为兼容数据源。
