# Changelog

## 0.1.4

- 本地任务按队列执行，默认同时运行 1 项、最多等待 31 项；支持取消排队任务和重启后恢复等待任务。
- 优化任务历史读取和页面刷新，减少历史任务较多或页面闲置时的资源消耗。

## 0.1.3

- 整合本次应用更新并重新验证桌面平台发布。

## 0.1.2

- 新增 Linux AMD64 独立安装包，按平台携带固定版本原生依赖，在无外网环境验证实际任务。

# 更新记录

## 0.1.1

首次公开发布。内置 Czkawka、FFmpeg 和 ffprobe，支持 14 类扫描/整理命令、参数表单、结果分组和报告导出。Agent 通过随包 CLI skill 操作，共享任务记录。

支持 macOS Apple Silicon（darwin-arm64）。固定运行依赖随包提供，首次使用在本机还原并校验，无需额外下载引擎或安装查看软件。
