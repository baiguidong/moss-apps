# AI 自测

安装后从「设置 → Apps → AI 自测」勾选项目并开始。也可在会话选中 AI 自测 App 后使用自测工具。需要 Moss Host API 3.12。

使用主 Moss 当前真实模型和完全放行授权，启动独立测试实例；已安装 App、配置及个人资源由 Host 复制，业务数据保持隔离。Playwright MCP 随本 App 提供，无需另外安装 Browser Use。

首次准备后复用安装环境；每批最多 3 项创建新的控制会话，默认清理上轮测试会话、项目、工作流与任务，再重新打开目标窗口。可取消“开始前自动清理”保留数据；支持单独打开、关闭、同步环境、清理测试数据。停止 AI 操作和测试完成后保留测试窗口及产物，自动打开内嵌截图的 HTML 报告。

清单位于 resources/self-tests/catalog.json，包含 59 项测试、10 个模块，31 项默认选择（其中 2 项调用目标文本模型）。每轮保存清单、观察和证据，全部标准与截图齐全才能通过。

不迁移旧内置自测数据或配置。运行记录保存在 App 私有目录 runs/，隔离实例由 Host 管理。App 关闭页面后继续执行；停用、撤权或退出 Moss 会回收控制会话和测试进程。

开发：bun run check、bun run test、bun run build。运行依赖随包提供，源码及固定 SDK 随版本保存。

51 项检查（包含全部默认 31 项）由固定 Playwright 脚本真实点击、等待条件、断言并截图。一个页面执行器与一个图片验收器重叠工作：截图队列最多 6 项，每批最多 3 项，超过 10 张、8 MiB 或 450 万总像素时拆批；目标模型调用前排空验收。每批使用新会话，全部截图随首轮消息送达，AI 只提交结果或请求具体补查，不重做成功操作。正常验收最多 45 秒；漏交最多在原截止时间内补交一次。所有固定操作后，继续执行选中的 8 项动态场景，再独占页面补查，每项最多 60 秒，整轮补查最多 120 秒。结果工具回执保存后正常结束，不额外调用模型，也不伪装用户中断。截图不足或超时显示“验收未完成”，不计为通过。

控制会话只接收当前项目、实际观察与原生截图，不重复携带整轮历史、脚本和完整 App 授权清单；浏览器脚本回显删除，长观察存文件。Core 使用专用提示和工具范围；GPT 网关的工具图片转为原生图片块，避免 base64 被当成文本和模型看不到截图。该 Core 修复需要更新并重启 Moss。原生 PDF 通过实际查看器截图、页码与缩放控件验证；权限模式使用页面内确认框，先验证取消不改变权限，再明确确认恢复测试权限。

设置页提供当前项目及检查步骤、实时计时、测试与复核（不含环境准备）及分阶段耗时和结果展开查看；“默认项目 / 界面检查 / 全部项目 / 重测问题项”可快速选择范围，支持按模块和关键词筛选、整组勾选。界面检查不在目标窗口发起聊天，但控制 AI 仍使用当前模型。

UI 验证：构建后运行 `node tests/ui.browser.mjs <截图目录>`，覆盖深浅主题、窄窗口、范围选择、运行锁定、停止和失败详情；真实模型及 CDP 全流程使用 Core 的 `ui/tests/helpers/run-self-test-app.mjs`。运行耗时会随模型与目标环境变化，比较时使用包含环境准备、执行、复核和报告写入的总耗时，另列阶段时间，不能把单纯页面操作耗时当作完整验收耗时。

详细覆盖映射见 [测试清单](resources/self-tests/README.md)。单项可独立运行，外部服务缺失记录阻塞。整轮超时按所选项目的时间预算相加再加 5 分钟准备时间（至少 45 分钟）；这只是上限，不是预计耗时。

命令行真实验证：`--all` 选择全部 59 项，`--default` 选择默认 31 项，也可传入具体 case ID。

程序失败先带原截图进入验收，明确失败直接保留；仅证据不足再补查。重试成功不能覆盖产品偶发问题，只有测试定位或断言错误才能附带明确 `correction` 依据改判。

0.1.9 需要 Host API 3.13.0（含 `controller.turn.finish`）；升级自测 App 前同时更新并重启 Moss 宿主。环境设置、已安装 App、资源或凭据变化会在下一轮同步，未变化的安装包与工具链复用。
