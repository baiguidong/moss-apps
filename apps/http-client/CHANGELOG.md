# 更新记录

## 0.1.4

- Host 协议统一声明在 `host.protocols`，供 UI 和 Backend 共用。
- 同步 SDK 3 调用保障、契约校验和错误语义。

## 0.1.3

- 适配 Host API 3：使用绑定当前 App 的 SDK，统一调用取消及错误处理。

## 0.1.2

- 适配 Host API 2.9 的启动前取消，移除每 250 ms 重发取消的定时器。
- 保留请求结束确认与监听清理，覆盖包加载、运行环境准备和网络请求期间的取消。

## 0.1.1

- 移除 HTTP 请求的 AI 工具注册，保留 App 页面的请求编辑、发送与响应查看。

## 0.1.0

- 新增独立 HTTP 调试 App：常用方法、查询参数、请求头、JSON/文本/表单正文、Basic/Bearer 鉴权。
- 本地 Node 执行请求，支持超时与取消；跨站重定向移除鉴权，不转发跨站正文或降级 HTTPS。
- 查看状态码、耗时、响应头、JSON 原文与格式化结果；保留大整数精度，二进制以 Base64 展示，响应限制为解压后 1 MiB。
- 保存不含参数值、正文和鉴权的本地请求模板；跟随 Moss 外观，适配窄窗口，并提供 HTTP AI 工具。
