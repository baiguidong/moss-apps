# Changelog

## 0.2.4

- 将服务注册检查延迟到实际请求，避免初始化阶段阻塞。


## 0.2.3

- 整合本次应用更新并重新验证桌面平台发布。

## 0.2.2

- 新增 Linux AMD64 支持；由 Linux CI 执行检查、测试、构建、源码独立重建及 Backend 验证。

# 0.2.0

- 使用 AntV G6 展示记忆知识图谱，支持力导向布局、分类配色、有向关系和关联高亮。
- 点击节点查看记忆内容，支持搜索、类型筛选、列表、分页、缩放与自动刷新。
- 新增只读图谱接口，直接读取 App 持久记忆，支持空数据、异常文件及大型结果的明确反馈。

# 0.1.0

- 新增独立记忆 App，启用后自动注册和检查随包提供的 Memory MCP。
- 提供状态、重连、持久数据位置、工具搜索与排除工具设置。
- 记忆跨版本和重启保留，多个对话写入使用互斥锁。
- 随包提供固定版本服务、生产依赖、许可证与可重建源码。
