# Changelog

## 0.2.2

- 数据库查询包支持 macOS、Windows 和 Linux；Windows 使用 `cmd /c npx` 启动 DBHub。

## 0.2.1

- 修复较矮窗口中表单与底部按钮重叠，内容独立滚动、操作栏始终可见。
- 优化小窗口间距及深浅色滚动条，保留键盘操作与错误提示的可达性。
- 按驱动启动、数据库名称、认证和网络原因区分连接失败提示，不输出敏感连接信息。

## 0.2.0

- 在 App 内动态新增、编辑、删除和启停多个数据库连接，保存后可测试连接。
- 自动管理连接配置文件，支持常用连接字段、自定义连接地址、只读、行数与超时设置。
- 密码加密保存，支持留空保留、替换与清除；旧连接可从页面迁移。
- 未配置时展示添加连接入口，不再依赖缺失的默认 TOML 文件。

## 0.1.0

- 新增配置型数据库查询 App，固定 @bytebase/dbhub 1.5.0，使用本地 stdio 服务。
- 通过用户指定的 TOML 文件配置数据源和只读 SQL 工具，提供带行数与查询超时限制的示例。
- 数据库连接地址使用 Core Credential Vault 保存，不预设数据库、不创建演示数据；要求 Host API 3.9。
