# Changelog

## 0.2.0 - 2026-09-24

- 顶部改为“全部文件／上传／下载”三个独立标签，切换保留目录和任务；创建任务后进入对应标签，完成后保持当前页面。
- 全部文件支持在当前目录中新建目录，提供名称校验和同名冲突提示。
- 新增文件删除确认，默认聚焦取消；成功后刷新列表与容量，失败时保留文件并显示原因。
- 复用 Core 的 `folders.create` 和 `files.delete`，新增 `cloud-storage:delete` 权限及对应 Backend action、Schema。
- 补充目录与删除的请求竞争、权限失败、账号切换、键盘操作及真实 Core 嵌入验证。

## 0.1.1 - 2026-09-24

- 合并目录与操作工具栏，移除嵌入 Moss 后重复的标题和图标，增加文件列表可用空间。
- 上传完成后，自动展开的传输面板收为摘要；主动查看、暂停、失败及未确认取消的任务保持可见。
- 完成记录保留上传／下载方向，精简重复进度信息；创建任务反馈合并到传输状态，不再用提示条或浮层遮挡文件与操作。
- 移除传输面板的常驻刷新和说明栏，列表刷新明确为“更新列表”。
- 增加真实 Core 嵌入容器的桌面验证，以及完成收起、短窗口和批量任务竞争的回归测试。

## 0.1.0 - 2026-09-24

- 新增个人云端文件列表、目录导航、刷新与游标分页。
- 支持多文件上传、单文件下载，以及传输进度、暂停、继续、取消和历史恢复。
- 接入 Moss Host API 2.2，复用当前远程账号和云端存储；处理同名冲突、部分失败、账号变化及连接不可用。
- 提供紧凑的文件工作区、窄窗口布局和明确标注的浏览器演示。
