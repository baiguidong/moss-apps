# Linux speech synthesis

- sherpa-onnx Node addon and Linux x64 CPU runtime, version 1.13.8, Apache-2.0. Upstream source and build instructions are at https://github.com/k2-fsa/sherpa-onnx/tree/v1.13.8 .
- MeloTTS Chinese model, MIT, copyright 2024 MyShell.ai. Upstream source is https://github.com/myshell-ai/MeloTTS and the model conversion is https://github.com/k2-fsa/sherpa-onnx/tree/master/scripts/melo-tts . The license supplied with the verified model archive is included next to the model in the Linux package.
