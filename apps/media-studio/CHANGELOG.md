# 更新记录

## 0.2.1

- 工作区导航支持折叠并记住选择，分隔线贯穿内容区。分镜编辑默认使用紧凑导航和顶部项目选择器。
- 分镜页可直接新建、命名和打开视频项目。「创作工作台」可从项目或使用指南返回分镜首页。
- 任务中心按可用宽度排列列表与详情，窄窗口支持进入详情并返回原任务行。

## 0.2.0

- 新增工作台，分组呈现六个工具与最近任务。窄窗口可从下拉菜单切换工作区。
- 任务中心统一展示图片、音视频、字幕、分镜和口播记录，可搜索、筛选、重试，或打开对应结果与编辑器。
- 音视频页面支持原文件转写和 GIF 宽度、帧率设置，在工作区之间切换时保留当前媒体参数。

## 0.1.1

- 文件管理可在运行视频任务时通过 Moss 跨 App 接口复用工坊提供的 FFmpeg 和 ffprobe。

## 0.1.0

- 新增多媒体工坊，接入图片处理、音视频处理、转写字幕、分镜动画、数字人口播与角色对话。
- 会话提供 12 个工具。图片页保留原有编辑、批处理、对比、历史和导出流程。
- 支持从旧图片工具和音视频工坊实例复制历史数据。
- 为 Apple Silicon 和 Linux AMD64 构建独立包。Linux 使用随包 Melo 中文音色。
