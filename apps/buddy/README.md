# Buddy 伴侣精灵

官方独立 App。给宠物取名并孵化后，可以和它真实聊天；选择小苔团、机器人或光球形象。宠物档案和历史保存在 App 私有目录，升级和换形象不会重置出生时间。

需要 Moss Host API 3.6 和可用的 Moss 模型配置。孵化本地完成；欢迎语为固定见面问候，后续回复经 `moss.agent/v1` 执行，失败会如实显示。内置行为规则随 App 发布，可在伙伴设置选择已有 Agent/助手。

配置能力经 `moss.settings/v1` 提供，包含 Desktop、Agent 用户/项目/本地、会话、App、MCP、助手规则和通用/终端偏好。目录返回实际支持的字段和目标；密钥通过相应凭据页面修改。当前没有远端 Server 管理 API 的字段不会被伪装成可修改。默认使用全部可用工具与全部执行权限；可在 App 内切回确认模式或限制工具。全部权限依赖安装时授予的独立权限，确认模式下由 Host 展示高影响变更。结果携带生效状态与撤销回执。

收起时仅显示 56 × 56 的宠物小图标，点击展开，拖动可移动。人设按实际会话初始化一次，普通后续消息只发送用户原文；改变设定时更新一次。Moss 个性化设置不再包含 Buddy 专属入口。

界面沿用 Moss 的主题色、字体和控件样式，背景与深浅色跟随桌面外观；聊天字号、行高和间距也使用 Moss 的设置。换宠物形象不改变界面配色。

“Moss 设置”按功能展示中文名称、用途和当前状态，支持直接开关、选择与撤销；完整的高级设置仍可通过对话操作。

Buddy 的使用指导也包含实际操作：如“字太小，帮我调大一点”“联网搜索用不了，帮我检查并修好”。对话规则要求先检查实际字段、范围与当前值，明确委托的调整直接执行，随后读取结果并说明生效时间；只报告异常时先检查并提出具体建议，撤销使用真实修改回执。伙伴的配置开关和执行模式变化会更新已有会话的上下文。手册支持自然问句检索，包含配置调整、范围、网页搜索排查与 SDK 指引；它解释用法，实际能力和状态仍以 Host 查询为准。

通知读取需要 `notifications:read`，已读状态与 Moss 通知中心同步。Agent 工具范围由绑定和 Host 授权共同约束。关闭配置功能后，App Backend 也拒绝写入；不仅隐藏 UI。

```sh
bun run check
bun run test
bun run build
```

发布包通过仓库打包工具生成，包含源码与 checksums；市场发布还需发布者签名。App 随 Moss 进程运行，退出 Moss 后不继续服务。
