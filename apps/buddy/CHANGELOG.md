# Changelog

## 0.1.5

- 孵化时切换精灵类型，上方预览立即切换到相应形象。

## 0.1.4

- 整合本次应用更新并重新验证桌面平台发布。

## 0.1.3

- 新增 Linux AMD64 支持；由 Linux CI 执行检查、测试、构建、源码独立重建及 Backend 验证。

## 0.1.2

- 对齐 Moss 的深浅主题、背景、字体、按钮、输入框和聚焦样式。
- 宠物形象仅改变宠物外观，界面统一使用 Moss 主题色。
- 聊天融入页面，去掉内层背景卡片；字号、行高和消息间距跟随 Moss 外观设置。
- 保留紧凑头部及透明的 56 × 56 悬浮图标。

## 0.1.1

- 收起为 56 × 56 图形图标，点击展开、拖动移动。
- 聊天页面取消双层边框和重复标题，小头像与名字单行展示；空闲文案、陪伴天数与常驻快捷提示退出聊天主体。
- 默认全部可用能力与全部执行权限，可切换确认模式或限制工具。
- 人设按会话初始化，连续消息不再重复发送；重启与设定变化保持正确语义。
- Moss 设置改为中文功能名称、当前状态、直接开关与撤销。
- 仅在目标值未变化时自动重试配置冲突；兼容有效的 App 工具权限规则。
- Buddy 设置统一放在 App 内，移除个性化专属入口。

## 0.1.0

- 孵化、命名和三种宠物形象，内置助手与真实 Moss Agent 对话。
- App 私有聊天历史、性格设置、可选 Agent/助手和停止回复。
- Moss 全域配置目录、读写与撤销工具，使用手册和通知中心接入。
