# 更新日志

## 0.1.15

- 发布包包含完整源码、固定 SDK 和依赖锁文件，支持安装后恢复、跨目录重建及继续迭代。
- 通过 CI 构建、各桌面平台验证及解包后独立重建后签名发布。

## 0.1.14

- 随安装包提供完整源码、固定 SDK 和锁定构建入口，支持安装后直接恢复迭代。


## 0.1.13

- Host 协议统一声明在 `host.protocols`，供 UI 和 Backend 共用。
- 任务变更游标恢复漏事件；公共有界结果读取与文件范围读取。

## 0.1.12

- 适配 Host API 3：使用绑定当前 App 的 SDK，统一调用取消及错误处理。

## 0.1.11

- 适配 Host API 2.9，使用有类型的 Tasks / Execution 客户端。
- 任务与执行状态通过事件及时更新，取消 400 ms 执行轮询与每秒任务轮询，保留 5 秒状态查询兜底。
- 处理订阅前完成、重复/旧事件和取消时的监听清理；工作流定义与运行数据格式保持不变。

## 0.1.10

- 工作流作为独立 App 上架，安装后即可使用。
- 在 Moss 普通会话中创建、修改和运行工作流，使用自然语言填写输入。
- 支持从“选择资源 → 工作流”和 `@` 选择已发布流程。
- 在会话左侧查看流程和节点状态，支持停止、恢复与结果追问。
- 移除历史迁移、内置模板、JSON 编辑器和重复运行入口。
- 需要支持 Host API 2.8 的 Moss；发布前验证签名包的安装与运行。
