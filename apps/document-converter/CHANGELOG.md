# 0.4.4

- 新任务、导入副本、生成文件、预览和修改版本保存到当前会话 workspace；不迁移旧 App 私有目录中的数据。

# 更新记录

## 0.1.1

首次公开发布。内置 Pandoc 与 Typst，提供输入/输出格式选择、转换参数、批量转换、文档预览和 PDF 导出。Agent 通过随包 CLI skill 操作，共享任务记录。

支持 macOS Apple Silicon（darwin-arm64）。固定运行依赖随包提供，首次使用在本机还原并校验，无需额外下载引擎或安装查看软件。
