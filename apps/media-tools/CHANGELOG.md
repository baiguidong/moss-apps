# 更新记录

## 0.3.2

- 角色对话使用会话提示词保存表达偏好，Moss 聊天记录中只显示用户输入和角色回复。需要 Host API 3.24.0。

## 0.3.1

- 明确分镜成片和口播试听的适用范围，补充口播设置查询与 FFmpeg 高级处理参数的说明。

## 0.3.0

- 原语音转写和分镜工作台接入音视频工坊，保留字幕校对、主会话创作与成片预览。
- 七个会话工具覆盖剪辑、转写、项目保存、渲染、查询、取消、导出。剪辑、转写与分镜共用按需后端和任务队列，分镜任务固定提交时的项目版本。

## 0.2.0

新增本地数字人口播工作台、原创角色小墨、GLB 导入、配音字幕与 MP4 导出。支持 Moss 讲稿工具、角色文字对话与可选语音转写。

## 0.1.0

首次提供FFmpeg 音视频处理和媒体预览；页面与 Agent 共享任务记录和结果。
