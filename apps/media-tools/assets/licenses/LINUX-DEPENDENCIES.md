# Linux dependencies

FFmpeg 8.0.0: @drbearzay/ffmpeg-linux-x64. GPL version 3 or later (`--enable-gpl --enable-version3`, no nonfree); exact build configuration is in ffmpeg-version-linux.txt. Pinned download and binary hashes are in resources/ffmpeg.json.

Upstream source and build recipes: https://ffmpeg.org/download.html and https://github.com/BtbN/FFmpeg-Builds .

Linux CPU dependencies are selected separately from the existing macOS assets; all original upstream license files remain included.
