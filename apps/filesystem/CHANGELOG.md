## 0.1.1

- 会话 workspace 自动追加并优先使用，App 公共目录可留空；清空公共目录后会话工具仍可用。
- 设置入口位于“设置 → 工具”，支持多个公共目录。
- “重新连接”调整为“检查服务”，验证 MCP 进程启动、握手和工具发现。
- 验证并发会话目录隔离、公共目录访问、空配置启动与本地 Node 服务。

## 0.1.0

- 新增独立文件系统 App，提供目录设置、连接状态、重连与工具详情页面。
- 配置后自动注册随包的 Filesystem MCP；首次安装等待显式目录配置。
- 固定 App 目录授权范围，支持排除工具，清空配置不删除文件。
- 提供离线依赖、许可证、可重建源码和真实 Host 验证。
