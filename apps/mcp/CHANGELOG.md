# Changelog

## 0.1.5

- Host 协议统一声明在 `host.protocols`，供 UI 和 Backend 共用。
- 配置内置服务前使用 Host 能力发现检查支持、权限和可用状态。

## 0.1.4

- 适配 Host API 3：使用绑定当前 App 的 SDK，统一调用取消及错误处理。

## 0.1.3

- 首次打开、启用服务及修改配置后自动加载当前服务的工具目录。
- 展示加载、取消和失败状态；过期响应不会覆盖新的配置或启用状态，失败后可手动重试。
- 配套 Moss Desktop 修复“设置 → 工具”遗漏 App 动态 MCP 工具的问题，显示服务状态、排除项并自动发现工具。

## 0.1.2

- 启动内置 MCP 时自动开启本机 Chrome CDP，复用已有浏览器，隔离并保留登录目录。
- 启动失败显示具体原因，支持修改浏览器配置并重试；停止 MCP 不关闭共享浏览器。

## 0.1.1

- 将 Playwright MCP 0.0.83 及依赖打包为内置 `playwright-cdp`，复用 Moss Node 运行时，无需联网安装或 npm。
- 启动时注册服务，迁移同版本 npx 预设并保留参数与停用状态；升级、换电脑自动更新内置启动器路径。
- 默认输出目录使用 `~/.moss/artifacts/playwright`，配套 Desktop Host 在执行时展开当前用户目录。
- 补充 CDP 使用前提与启动参数路径说明。

- 合并首次使用空状态，主页面只保留一个添加服务入口。
- 精简重复标题、统计和装饰，使用紧凑工具栏与服务分栏。
- 区分加载、失败和空列表，优化窄窗口及低高度窗口中的布局与表单。

## 0.1.0

需要提供 Host API 2.4 的 Moss Desktop。

- 从桌面设置中抽出 MCP 管理，支持 stdio、HTTP 和 SSE 服务。
- 新增服务搜索与筛选、连接检查、工具目录和浏览器授权。
- 使用 Moss 配色、紧凑工作区及运行时外观同步，适配浅色、暗色和窄窗口。
- 通过 `moss.mcp/v1` 管理独立配置和加密凭据，迁移原有桌面服务。
