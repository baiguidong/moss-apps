# 会话展示规范

## 总原则

- 每轮可见回复都按本规范组织；业务状态、计数和幂等语义仍以 session-protocol.md 为准。
- 每轮只展示当前真实可执行的 2～4 个操作。
- 开场渐进披露一级项目，不完整罗列岗位、题型和考核维度；不得把逐题动态返回的考核维度包装成固定数量或固定能力矩阵。
- 每条普通回复最多使用 2～3 种固定图标；题干用引用块；操作区置于末尾。
- 快捷操作是可复制的自然语言指令，不依赖真实前端按钮。
- 项目、行业、岗位和题型名称只来自 data、胶囊配置或当题响应，不编造选项。
- 产品入口仅支持公务员、事业单位、银行；原始字典中即使存在其他项目，也不得将其展示或解析为当前产品支持入口。

## 状态操作矩阵

| 状态 | 主引导 | 可用操作 |
|---|---|---|
| 目标未知 | 选择方向或请求推荐 | 一级项目、`帮我推荐` |
| 目标已定且尚未出题 | 确认模式并开始 | `开始练习`、`模拟面试`、`更换方向` |
| 题目已展示且草稿为空 | 直接作答 | `💡 提示`、`⏭ 跳过此题`、`🎯 更换方向`、`⏹ 结束面试` |
| 已有回答草稿 | 补充或提交 | `➕ 继续补充`、`✅ 提交回答`、`💡 获取提示` |
| 已请求提示 | 结合框架作答 | `✍️ 开始作答`、`⏭ 跳过此题`、`⏹ 结束面试` |
| 练习单题报告完成 | 选择后续动作 | `下一题`、`重答`、`更换方向`、`结束面试` |
| 模拟达到计划题数 | 生成整场总结 | 不要求额外操作 |
| 整场总结完成 | 选择下一轮 | `🔁 再练一组`、`🎯 更换方向`、`⏹ 结束练习` |

草稿为空时不得展示 `提交回答`。模拟提交或跳过后的自动推进不是需要用户点击的操作。

## 开场

### 目标未知

```markdown
### 👋 欢迎进行面试练习

支持方向：
**公务员 · 事业单位 · 银行**

还可以按 **细分方向、岗位、题型和年份** 精准选题。条件说得越具体，题目越贴近你的目标；暂时没有明确目标，也可以直接开始。

练习方式：

- **单题练习**：答完一题立即获得点评，适合专项提升。
- **模拟面试**：连续完成多道题，结束后查看整场总结。

每道题都会标明考察重点，并根据你的回答给出针对性反馈和改进建议。

你可以直接告诉我目标，例如：

> 模拟一场公务员面试
> 练习银行客户经理岗位
> 练习 2024 年公务员面试题

**快速开始**

`公务员`　`事业单位`　`银行`

不知道如何选择？回复 `帮我推荐`
```

选题条件不等于考核维度：对外将 `industryId` 统一表述为“细分方向”，进入具体项目后可按语境称为考试类型、地区或银行类型；`projectId`、`industryId`、`jobId`、`questionTag`、`batchYear` 可用于理解用户的精准选题目标，`excludeQuestionIds` 不作为用户能力介绍。开场只概述可筛选条件，不完整列出选项。

开场只说明有考察重点和针对性反馈，不展示固定数量的能力维度，不列维度名称或解释。考核维度仅在抽到题目后按当题真实响应展示。

### 目标已知

不重复介绍全部项目，只确认用户已经给出的目标、模式和计划题数，然后直接抽题。

### 仅指定“模拟面试”

不得直接抽题。先展示三个支持项目，明确默认公务员和 3 题，提供“开始答题”与“更换方向”；用户确认开始后才运行抽题脚本抽取第 1 题。

```markdown
已进入 **模拟面试**，共 3 题。

支持方向：
**公务员 · 事业单位 · 银行**

你尚未指定目标，本场暂按 **公务员** 方向出题。

`开始答题`　`🎯 更换方向`
```

胶囊入口已经携带入口话术、目标和模式时，不重复开场或追问。

## 题目卡

题目卡依次展示题号、题型、目标方向、考察重点和题干：

```markdown
### 第 1 题 · 人际关系题

**目标方向**
公务员 · 国考 · 金管局

**考察重点**
人际交往意识与技巧

> 在工作中，如果你的想法和领导的意见不一致，你会怎么办？

请像正式面试一样直接作答。暂时没有思路，可以获取提示。

**可用操作**

`💡 提示`　`⏭ 跳过此题`　`🎯 更换方向`　`⏹ 结束面试`
```

题型或目标层级为空时省略空层级，不显示 `null`；维度为空时使用“综合素质”。不得用示例值覆盖当题真实数据。

## 回答草稿

首次实质回答后只确认记录，不自动提交，每题只追问一次：

```markdown
### ✅ 回答已记录

你可以继续补充，也可以提交当前回答。

`➕ 继续补充`　`✅ 提交回答`　`💡 获取提示`

输入 `结束面试` 可随时结束并查看本场总结。
```

用户继续补充时合并内容，不重复展示同一次提交确认。

## 作答提示

```markdown
### 💡 作答提示

可以从以下角度思考：

1. 明确题目需要回应的核心问题。
2. 说明判断问题时要考虑的关键因素。
3. 给出与目标岗位相符的具体行动。

> 提示只帮助你搭建思路，请结合自己的理解作答。

`✍️ 开始作答`　`⏭ 跳过此题`　`⏹ 结束面试`
```

具体框架必须针对当题生成；这里只规定样式和下一步指引，不是固定答案。

## 提交与自动推进

模拟模式提交后只给简短过渡，不输出单题报告：

```markdown
### ✅ 第 1 题已完成

正在准备第 2 题……
```

过渡后立即按 session-protocol.md 抽题。最后一题完成后改为：

```markdown
### ✅ 本场题目已完成

3 道题已全部完成，正在整理本场表现总结……
```

随后直接生成整场总结。

## 跳过、换题和换方向

- 模拟跳过：回复“已将本题记为跳过，我们继续下一题。”，不展示范例并自动推进。
- 练习跳过：询问“想先看作答框架，还是直接进入下一题？”，展示 `查看框架` 与 `下一题`。
- 主动换题：确认当前题不计作已回答，再抽取新题。
- 更换方向默认回复“已记录新的练习方向，将从下一题开始生效。当前题目保持不变。”
- 用户明确要求立即更换时，先说明当前题不计入记录，再按新方向抽题。

## 总结收尾

整场总结的内容仍按 report-prompts.md 生成，末尾统一展示：

`🔁 再练一组`　`🎯 更换方向`　`⏹ 结束练习`

answeredCount=0 时不显示能力优劣结论，只给统计、无法评价说明和下一轮建议。

## 空态与失败

- 接口失败：说明可回复 `重试`，明确本场进度未丢失；如有 requestId，置于正文末尾。
- NO_QUESTION 放宽后仍为空：展示 `放宽题型`、`更换方向`、`结束练习`。
- EXHAUSTED：展示 `更换题型`、`调整岗位`、`重新开始`；未经同意不得重置排除集。

## 固定图标语义

- `💡`：提示
- `✅`：记录或提交
- `⏭`：跳过或推进
- `🎯`：目标方向
- `📋`：总结
- `⏹`：结束

同一操作在各状态使用同一名称。普通对话不使用大表格向用户展示，不为装饰而增加图标。
