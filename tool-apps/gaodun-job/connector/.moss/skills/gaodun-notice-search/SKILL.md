# 招考公告检索（gaodun-notice-search）

基于 `search_notice` MCP 工具，从高顿公考业务系统检索官方招考公告，帮助用户了解哪些公告正在/即将/已经开放报名。

## 触发场景

- 用户查询某省份 / 某类型的招考公告，如"2026 年公务员安徽的公告有哪些"
- 用户要求汇总多省联考公告，如"2026 年多省联考公告汇总"
- 用户想了解公告的报名时间、招录人数、考试大纲、报考流程
- 用户想区分已发布 / 待发布公告，或按"即将截止""招考人数多"排序

## 核心能力

1. **多维检索**：按年份、考试地区、招考状态、考试业务类型组合筛选官方招考公告
2. **标题搜索**：支持按公告标题关键词检索（`keyword` 入参，支持跳字匹配，如"联考"可命中含"多省联考"的公告标题）
3. **多省汇总**：一次查询聚合多个省份的公告，可区分"汇总公告"(SUMMARY，聚合多个子公告) 与"普通公告"(NORMAL，单条)
4. **要点提炼**：对返回的公告列表提炼关键信息（发布状态、报名时间、招录人数等），剔除冗余内容，便于用户快速阅览
5. **灵活排序**：支持"最新""即将截止""招考人数多"三种排序

## 调用方式

调用 `search_notice` 工具，所有参数均为可选，不传则不限制：

| 参数 | 类型 | 说明 |
|------|------|------|
| keyword | string | 公告标题搜索关键词，支持跳字匹配，如"联考""选调"；与标题部分匹配即命中 |
| target_year | string[] | 年份列表，如 `["2026"]`、`["2026","2025"]` |
| area_list | string[] | 考试地区，格式 `"省-市-县/区"`、`"省-市"` 或 `"省"`，用 `-` 连接层级。**省级名称不能用简写**，如必须写"安徽省"而非"安徽" |
| recruitment_status | string[] | 招考状态，仅可填：`"即将报名"`、`"报名中"`、`"即将截止"`、`"报名结束"`、`"全部"`；传 `["全部"]` 或不传均表示不限 |
| exam_biz_type_list | int[] | 考试业务类型 id：1-公务员、2-事业单位、5-银行、4-国企、3-军队文职、7-教师、10-医疗、6-选调、9-遴选、8-选调生、11-三支一扶、14-大学生村官、12-基层工作者、13-公益性岗位 |
| sort_type | string | 仅可填：`"最新"`、`"即将截止"`、`"招考人数多"`，不传默认"最新"。**仅支持这三种排序，其他排序方式（如按报名时间、按地区等）一律拒绝** |
| page_num | int | 页码，从 1 开始 |
| page_size | int | 每页条数 |

## 使用流程

### 1. 解析用户意图，构造查询条件

- 公告标题关键词（如"多省联考""选调公告"）→ `keyword`
- 省份 → `area_list`（补全为行政区划全称，如"安徽"→"安徽省"）
- 考试类型 → `exam_biz_type_list`（映射为对应 id）
- 年份 → `target_year`
- 报名状态 → `recruitment_status`
- 排序需求（"哪个快截止"→"即将截止"，"哪个招人多"→"招考人数多"）→ `sort_type`

### 2. 调用并组织结果

- 返回列表中 `SUMMARY` 类型的为汇总公告（聚合多个子公告），`NORMAL` 为单条普通公告
- 向用户呈现时：按公告列出核心字段（名称、地区、类型、招考状态、报名时间、招录人数等），并附关键要点提炼
- 多省联考场景：明确标注各公告属于已发布还是待发布（由招考状态字段判断）

### 3. 结果为空时

返回提示文本时，建议放宽筛选条件后重试，并告知用户可去掉某些筛选维度。

## 输出格式约束（强制）

**必须严格遵守以下输出结构，不得自行调整顺序或增减字段：**

### 每条公告的显示格式

```
【公告标题】完整标题

📌 主要信息
• 报名状态：[即将报名/报名中/即将截止/报名结束等]
• 报名时间：YYYY-MM-DD 至 YYYY-MM-DD
• 公告标签：[如：多省联考/国考/省考等，无标签则省略此行]

📊 次要信息（可选）
• 岗位数：X 个
• 招考人数：X 人
• 其他信息：[如考试科目、特殊要求等，无则省略此行]
```

### 显示规则

1. **必须按顺序展示**：公告标题 → 主要信息（报名状态、报名时间、公告标签）→ 次要信息（岗位数、招考人数、其他信息）
2. **主要信息必填**：报名状态、报名时间必须显示；公告标签有则显示，无则跳过该行
3. **次要信息选填**：仅当字段有值时才显示对应行，值为空或不存在的直接跳过
4. **禁止自由发挥**：不得添加不在上述列表中的字段（如发布时间、浏览量、收藏数等），不得调整显示顺序
5. **空值处理**：某个字段值为空时，直接跳过该字段所在的整行，不显示"暂无""无"等占位符
6. **列表展示**：多条公告时，用分隔线（---）清晰分隔，每条公告独立展示

### 禁止行为

- ❌ 调换字段顺序（如把报名时间放在报名状态前）
- ❌ 增加额外字段（如"发布时间""来源""浏览量"等）
- ❌ 使用非指定的 emoji 或图标
- ❌ 折叠或隐藏主要信息
- ❌ 将次要信息提升为主要信息展示

## 注意事项

- 地区名必须使用完整行政区划名称（"安徽省"而非"安徽"、"上海市"而非"上海"），市/县/区层级可选
- 招考状态与考试业务类型取值必须与上文完全一致，否则可能查不到结果或服务端报错
- **排序仅支持 `"最新"` / `"即将截止"` / `"招考人数多"` 三种**
- `keyword` 为公告标题搜索关键词，支持跳字匹配（与标题部分匹配即命中），可与其它筛选条件组合使用
- 用户未明确省份/类型时，不自行猜测，按用户原话原样传入或先询问
