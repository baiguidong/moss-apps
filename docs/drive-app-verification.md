## Core 已知限制

当上传初始化被服务器以同名冲突拒绝后，Host 的取消逻辑可能继续查询一个不存在的上传初始化记录，返回 `CANCEL_NOT_CONFIRMED`。页面保留“已暂停”和未确认原因，并提供“重试取消”，不把它标记为已取消。正常已初始化上传的取消已通过真实服务验证。本次没有修改 Core 的传输实现。
