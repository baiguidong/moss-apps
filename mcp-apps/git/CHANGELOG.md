# Changelog

## 0.1.2

- 转为配置型 App，删除独立 UI、Backend 和 Node Git MCP 实现，固定使用官方 Python 服务 2026.8.18。
- Core 复用独立 Python 环境，校验仓库访问范围；默认只使用会话 workspace，显式 repo_path 可选择公共仓库。
- Git 默认从 PATH 查找，也可指定完整路径；升级保留旧目录、程序路径、禁用工具、启停和服务身份。
- 要求 Host API 3.11。

## 0.1.1

- 会话 workspace 自动追加并优先使用，App 公共目录可留空；清空公共目录后会话工具仍可用。
- 设置入口位于“设置 → 工具”，支持多个公共目录。
- “重新连接”调整为“检查服务”，验证 MCP 进程启动、握手和工具发现。
- 验证并发会话目录隔离、公共目录访问、空配置启动与本地 Node 服务。

## 0.1.0

- 新增独立 Git App，提供仓库范围、Git 路径、排除工具、连接状态与重连页面。
- 将官方 Git 参考服务的 12 项工具适配到 Node 后台，调用本机 Git，无需 Python/uv。
- 首次安装等待显式配置，清空配置保留仓库；验证仓库、暂存路径与工具参数。
- 随包提供生产依赖、来源许可证、参考源码和可重建工程。
