# Changelog

## 0.1.4

- 新增 Linux AMD64 支持，沿用 Host 管理的跨平台 MCP 运行环境。

## 0.1.3

- 转为 Core 托管的配置型 MCP App，移除独立界面、Backend、启动包装和依赖复制构建代码。
- 保留全局工具范围、会话独立历史、步骤修正与分支，以及关闭上游正文日志的行为。
- 固定通过 npx 启动上游 2026.8.31，首次连接可能需要下载依赖；要求 Host API 3.9。

## 0.1.2

- 新增“设置 → Apps → 分步思考”页面，展示连接状态、工具目录与全局使用范围，支持刷新和重新连接。
- 页面跟随 Moss 明暗主题；关闭页面后继续提供全局工具。

## 0.1.0

- 新增纯后端分步思考 App，启用后自动提供 Sequential Thinking MCP 工具。
- 支持步骤、修正与分支，独立连接保存独立的临时历史。
- 关闭上游步骤正文日志，随包提供固定依赖、许可证和可重建源码。
